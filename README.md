# GitCodeMGAL

App sencilla de una bola de color personalizable con montañitas de fondo. El color se elige con un selector hex y la bola salta cada vez que se presiona la barra espaciadora (se permite saltar múltiples veces en el aire).

## Uso

1. Abre `index.html` en tu navegador.
2. Elige el color de la bola.
3. Presiona la barra espaciadora para saltar tantas veces como quieras.
